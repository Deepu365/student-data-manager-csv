  # student-data-manager-csv
“This project simulates a lightweight data management system where student records are stored in a CSV file. I used Python’s CSV module and object-oriented programming to organize and handle the data efficiently.”
Student Data Manager (CSV-based)” is a Python project that:
Stores student details (name, age, marks)
Saves them into a CSV file
Reads and displays stored data
 It works like a mini file-based database system (no user interaction).
                     How it Works
Student data is defined inside the code
Python writes data into a CSV file
When program runs → it reads the file
Displays all stored student records
                   Flow
Predefined Data → Python Program → CSV File → Display Output
              Technologies Used
 Python
 CSV Module (File Handling)
 OOP (Class - Student)
                Output Example
Stored Data in CSV
deepu,20,85
liki,30,97
teja,50,85
👉 Program Output
All Students:
['deepu', '20', '85']
['liki', '30', '97']
['teja', '50', '85']
